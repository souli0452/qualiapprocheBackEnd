# Carte des menus de QualiSira, telle que le front la déclare.
#
# À QUOI ELLE SERT
# Sans elle, l'assistant ne connaît rien de l'application : interrogé sur « où se trouve… »,
# il produisait des chemins plausibles et faux — un menu « Paramètres », un onglet
# « Administration », un écran « Documentation à réviser », dont aucun n'existe. Il n'y a
# pas de mauvaise volonté là-dedans : un modèle de langue comble ce qu'il ignore. La carte
# lui donne la réponse, et lui retire la raison d'inventer.
#
# CE QU'ELLE N'EST PAS
# Une liste d'habilitations. Chaque entrée du menu réel est soumise à un module souscrit et
# à une permission ; l'assistant ne les voit pas et ne doit rien en conclure. Il nomme un
# emplacement, il ne promet pas un accès.
#
# SOURCE ET MISE À JOUR
# Relevée dans FrontQualiApproche, src/app/core/layout/component/app.menu.ts.
# Un menu ajouté là-bas et oublié ici fait mentir l'assistant. Le test
# CarteDesMenusTest en vérifie la forme ; la correspondance avec le front, elle, se
# revérifie à la main quand le menu bouge — voir outils/verifier-carte-des-menus.sh.
#
# FORMAT : une entrée par ligne, « Rubrique > Sous-groupe > Entrée = /route ».
# Les lignes vides et celles commençant par # sont ignorées.
