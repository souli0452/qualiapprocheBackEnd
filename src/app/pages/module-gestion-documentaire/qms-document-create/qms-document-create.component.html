Ce guide a pour but de vous accompagner dans la création d'un nouveau document Qualité. Veuillez lire attentivement les indications ci-dessous pour assurer la conformité de vos enregistrements.

1. Fichier du document

Les documents internes doivent obligatoirement être importés au format PDF pour assurer le filigranage automatique et la protection. Pour les documents externes, les autres formats (Word, Excel) sont acceptés.

2. Type & Service

Type : Permet de classer le document (Ex: Procédure, Manuel, Instruction).
Service : Identifie l'entité organisationnelle propriétaire du document (responsable de ses révisions).

3. Périodicité de révision

Indiquez en mois la fréquence à laquelle ce document doit être revu. Le système vous alertera automatiquement à l'approche de la date d'échéance. (Ex: 12 mois pour une revue annuelle).

4. Champs Métadonnées (Optionnels)

Organisme / Référence : Utiles pour les normes ou lois provenant d'instances officielles externes (ex: ISO, AFNOR, Législation).
Domaine / Statut légal : Fournissent un contexte de conformité réglementaire (ex: "Sécurité Environnement", "Obligatoire").

5. Options de diffusion

Confidentiel : Le document n'est visible que par les utilisateurs ayant reçu un droit d'accès explicite.
Document Externe : Cochez cette case s'il s'agit d'un document qui n'a pas été produit en interne, mais qui est applicable à l'entreprise.
